## Funcionalidades
- **Ejercicio 1 (`Ejercicio1`):** Implementación de la clase abstracta `Figura` con el método abstracto `calcularArea()`, extendida por `Rectangulo` y `Triangulo` para calcular sus áreas específicas (`FiguraPrueba`).
- **Ejercicio 2 (`Ejercicio2`):** Implementación de las interfaces `Volador` y `Nadador` en la clase `Pato`, demostrando herencia múltiple de comportamiento en `PatoPrueba`.
- **Ejercicio 3 (`Ejercicio3`):** Demostración y análisis de errores de compilación al omitir la implementación de métodos de una interfaz (`Jugador`) y al intentar usar el modificador `default` dentro de una clase abstracta (`Entrenador` y `UsoIncorrectoPrueba`).
